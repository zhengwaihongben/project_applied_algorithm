# Claude Code skills used in this project

Copied unchanged from the plugins we used while building the project. Claude Code loads them automatically from `.claude/skills/`.

| Skill | From | What we used it for |
|---|---|---|
| `brainstorming` | superpowers 5.1.0 | Design discussion that produced the spec, `docs/superpowers/specs/` |
| `writing-plans` | superpowers 5.1.0 | Task-by-task implementation plan, `docs/superpowers/plans/` |
| `requesting-code-review`, `receiving-code-review` | superpowers 5.1.0 | Review passes before merging, and handling the findings |
| `ponytail`, `ponytail-review`, `ponytail-audit`, `ponytail-debt`, `ponytail-gain`, `ponytail-help` | ponytail 5.3.3 | Keeping the code minimal ("smallest complete change") and reviewing it for bloat |
